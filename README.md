# 🛒 বাজার দর | BazarDor

**BazarDor** is a web application that helps users explore daily market prices and product information in one place. It provides a simple, user-friendly experience for checking prices and browsing products across different categories.

## 🛠️ Technologies Used

- **Next.js** — React framework for web development
- **React** — Building interactive user interfaces
- **JavaScript** — Application logic
- **Tailwind CSS** — Responsive styling
- **HeroUI** — UI components
- **React Hot Toast** — Notifications and feedback
- **Better Auth** — Authentication and user sessions

## ✨ Key Features

1. **Daily Market Prices** — Browse market prices and product information.
2. **Product Categories** — Explore products organized by category.
3. **Product Details** — View detailed information about individual products.
4. **Authentication System** — Sign up, sign in, and access protected pages.
5. **Responsive Design** — Enjoy a user-friendly experience on mobile, tablet, and desktop devices.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ruhulaminislam/assignment-seven.git
cd assignment-seven
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

> **Note:** Configure the required environment variables before running the project if authentication or API features depend on them.
